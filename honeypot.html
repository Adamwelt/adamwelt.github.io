Honeypot

Standing up an open wireless access point with Bettercap to attract and observe devices that connect to it automatically, without needing to touch a real network.

01What it is

A honeypot is a decoy system built to be found and used, so that whoever interacts with it can be watched. In a wireless context, this usually means broadcasting an open, unencrypted access point — often with a familiar-sounding name — and letting nearby devices connect on their own, either because a person joins it manually or because their device auto-reconnects to a remembered SSID.

02How it works

Many phones and laptops keep a list of networks they've joined before and will auto-join any open network that matches a remembered name. Bettercap can broadcast a fake access point with a common SSID, wait for devices to associate, and then log who connected and what they tried to reach — all without ever needing to break into an existing network.

  • Choose an SSID likely to match a network a device has joined before
  • Broadcast the fake open access point
  • Let nearby devices auto-connect
  • Log connecting devices and their traffic
  • Tear down the access point when done
1 · launch bettercap 
sudo bettercap -iface wlan0
2 · set the fake ap name 
set wifi.ap.ssid Free_WiFi
set wifi.ap.encryption false
3 · start the access point 
wifi.ap
4 · watch for connections 
net.probe on
net.show
5 · log connected traffic 
set net.sniff.output honeypot.pcap
net.sniff on
6 · tear down 
wifi.ap off
net.sniff off
Note

Auto-connect only fires for networks a device already trusts by name, so honeypots targeting a specific person usually rely on common SSIDs (airport, hotel, coffee-shop chains) rather than guessing at random. Traffic seen this way is still limited by TLS the same way any other sniffing is.

03Detection & defense

Because a honeypot works by impersonating a trusted name rather than exploiting a flaw, defense is mostly about not auto-trusting networks in the first place. The absence of encryption on a network that's normally protected is often the biggest tell.

  • Turn off auto-connect for open or unsecured Wi-Fi networks
  • Forget saved networks you no longer actually use
  • Treat an open network using a normally-secured name as suspicious
  • Use a VPN on unfamiliar networks so sniffed traffic is still encrypted end-to-end
